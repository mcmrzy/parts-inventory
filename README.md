# 📦 物料管家（Parts Inventory）

一个本地运行的电子元器件 / 物料库存管理系统，支持：

- **物料档案**：型号 / 名称 / 品牌 / 分类 / 封装 / 规格 / 结构化参数 / 照片 / 存放位置 / 参考价 / 备注
- **库存进出**：入库、出库、盘点修正，全部记**流水账**（谁、什么时候、为什么、变动前后）
- **预警**：低于预设下限标黄，缺货（≤0）标红，支持“只看预警”
- **AI 助手（对话 + 拍照）**：
  - 自然语言建档 / 增加 / 减少 / 盘点 / 删除 / 查找，如“新增 100 个 10kΩ 0805 电阻 三星”
  - **拍照录入**：给料盘 / 包装袋 / 实物拍照发给它，AI 识别丝印 / 标签后自动建档入库
  - 内置**演示模式**（不联网、不花额度），可先体验全流程
- **立创商城对接**：输入 `C` 开头编号（如 `C1710`）或商品链接，自动拉取型号、品牌、封装、参数、数据手册、图片并建档；重复编号会提示直接入库
- **检索 & 导出**：多字段模糊搜索、分类筛选、CSV / JSON 全量导出（含流水）
- **本地优先**：SQLite 单文件存数据，照片存本地目录，无任何第三方数据库 / 云依赖

---

## 快速开始

要求：**Node.js ≥ 22**（自带 SQLite，无需额外安装数据库）。

```bash
cd parts-inventory
npm install
npm start          # 默认 http://127.0.0.1:7860
```

Windows 用户也可以直接双击 **`start.bat`**（自动安装依赖并启动）。
启动后浏览器打开控制台里打印的地址即可。

> 首次打开默认是**演示模式**（AI 助手由本地规则模拟，不联网、不耗额度）。
> 想要真正的拍照识别 / 语义理解，见下面「配置 AI」。

### 方式二：Docker 部署（推荐）

要求：已安装 Docker Desktop（或任意 Docker 引擎）。

```bash
cd parts-inventory
docker compose up -d --build     # 构建镜像并后台启动
# 浏览器打开 http://127.0.0.1:7860
```

- **数据持久化**：`./data` 与 `./photos` 挂载到宿主机，升级/重建容器数据不丢
- **AI Key**：继续用页面「设置」保存（存于挂载的 data/config.json）；或在 docker-compose.yml 中取消 `PI_AI_API_KEY` 注释改用环境变量
- 常用命令：`docker compose logs -f`（日志）｜`docker compose restart`（重启）｜`docker compose down`（停止）
- **升级**：更新代码后 `docker compose up -d --build`
- 容器内监听 `0.0.0.0`，局域网设备可直接访问 `http://<电脑IP>:7860`

## 配置 AI（可选，推荐）

点右上角 **⚙ 设置**，选择服务商并填写 **API Key**，然后「测试连接」。

| 服务商 | baseUrl | 对话模型 | 视觉模型（拍照识别） |
|---|---|---|---|
| 智谱 AI | `https://open.bigmodel.cn/api/paas/v1` | `glm-4.6` | `glm-4v-plus` |
| 阿里云百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` | `qwen-vl-plus` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com` | `deepseek-v4-flash-vision-exp` | `deepseek-v4-flash-vision-exp`（同一模型即支持视觉） |
| Moonshot | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` | — |
| 自定义 | 任意 OpenAI 兼容地址 | 任意 | 任意 |

要点：

- **对话模型**需要支持**工具调用（function calling）**，否则建档 / 加减库存会失败。
- **视觉模型**只用于“拍照识别”；表格里“视觉模型”留空的模型无法识图。
- API Key 只保存在本机 `data/config.json`，不会上传到任何地方；也可以改用环境变量注入，不在文件里留明文：启动前设置 `PI_AI_API_KEY=sk-xxxx`（文件里已有 Key 时以文件为准）。
- 也可以全程用**演示模式**：它能演示建档 / 入库 / 出库 / 盘点 / 删除，但没有拍照识别和模糊语义。
- DeepSeek `deepseek-v4-flash-vision-exp` 是推理模型：对话 / 工具调用 / 拍照识别都支持，已按该模型完成实测。

## 日常使用

1. **新增物料**：右上角「新增物料」。填型号 / 名称即可保存；可点「查资料自动填写」输入立创编号补全。
2. **AI 建档**：点「✨ AI 助手」，打字或直接点示例按钮。
   - `新增 100 个 10kΩ 0805 电阻 三星`
   - `入库 50 个 C1710`（编号已存在会自动加库存）
   - `出库 20 个 C1710` / `盘点 C1710 为 30` / `删除 C1710`
3. **拍照录入**：AI 面板点 📷 选照片 → 输入“识别并录入这个物料”（配置视觉模型后生效）。
4. **库存操作**：行内 ＋入库 / －出库 可快速操作，填写原因；详情页可盘点修正并查看流水。
5. **立创补全**：新增物料时粘贴 `C1710` 或立创商品链接即可自动填充并入库。

## 功能亮点（v4）

- **AI 一条龙**：对话/语音输入（Chrome、Edge）/拍照识别建档；带编号指令秒回（本地快车道）
- **扫码查料**：工具栏「⌗ 扫码」调起手机摄像头扫元件包装条码/二维码，自动匹配库存；未匹配可一键转 AI 建档
- **补货清单**：缺货/预警物料汇总 + 建议补货量，弹窗查看、一键导出 CSV
- **重复检测与合并**：同编号/同型号重复档案一键检测，合并时库存累加、流水迁移、空字段互补
- **库存走势**：物料详情弹窗内近 30 条流水的存量曲线
- **每日自动备份**：`data/backups/` 保留 14 天

## 功能亮点（v4）

- **AI 一条龙**：对话/语音输入（Chrome、Edge）/拍照识别建档；带编号指令秒回（本地快车道）
- **📦 清单 / BOM**：把一个项目要用的料存成清单（数量可改），随时「缺料检查」看缺什么、缺多少；支持「整套领用」（库存不足会拦截）和「有多少扣多少」，出库自动逐项记账
- **🛒 缺料转采购**：缺料检查里一键生成 AI 补货指令，自动从立创查资料入库
- **⌗ 扫码查料**：扫元件包装条码/二维码自动匹配库存；物料详情可生成 **Code39 条码标签**打印，贴在料袋上扫码即达
- **💰 库存价值**：来料价合计（按币种折 CNY）与立创参考价合计对照，独立计算
- **补货清单**：缺货/预警 + 建议补货量，一键导出 CSV
- **重复检测合并**：同编号/同型号档案检测合并，库存累加、流水迁移
- **库存走势**：详情弹窗内近 30 条流水存量曲线
- **🖼 一键同步图片**：缺图物料自动补图——有立创编号从立创拉官方图，没有的按型号/描述从 Openverse 开放图库找相似图（自动标注"网络相似图"）
- **每日自动备份**：`data/backups/` 保留 14 天
- **可选访问口令**：`PI_TOKEN` 环境变量开启，局域网访问需输入一次

## 数据与备份

```
parts-inventory/
├─ data/inventory.db     # 全部数据（SQLite，单文件）
├─ data/config.json      # AI 配置（含 API Key，勿外传）
├─ photos/               # 上传的照片
├─ src/                  # 服务端
├─ public/               # 网页前端
└─ scripts/e2e.mjs       # 端到端自测
```

备份 = 拷贝 `data/` 与 `photos/` 两个目录；也可在页面「导出」生成 CSV / JSON。

## 局域网 / 多设备使用

默认只监听 `127.0.0.1`（仅本机，最安全）。想让手机在同一 WiFi 里访问：

```bash
HOST=0.0.0.0 PORT=7860 npm start
# 手机浏览器打开 http://<电脑局域网IP>:7860
```

⚠️ 本工具**没有账号体系**，开放到局域网后任何能访问该端口的人都可以读写你的库存，请只在可信网络中使用。

## 常见问题

- **端口被占用**：`PORT=7861 npm start`。
- **AI 返回 400 / “不支持”**：该模型不支持工具调用或图片，请换 `glm-4.6` / `qwen-plus` / `gpt-4o-mini` 这类模型。
- **拍照识别没反应**：确认“视觉模型”已填，且当前不是演示模式。
- **立创查询失败**：该功能调用立创官网公开详情接口，若提示限流/无数据可稍后再试；被编号影响的只有 C 开头的商品。
- **换电脑/迁移**：把整个文件夹拷走，`npm install && npm start` 即可，数据随文件夹走。
